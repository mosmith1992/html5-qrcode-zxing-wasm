# Project Fork: Optimized Scanner with zxing-cpp WASM

> This is a forked repository, please refer to the original repository for more information.
> Optimized with **zxing-cpp wasm**, fixing the low recognition success rate issue of the original library.

## ✨ Highlights
- Replaced the original decoder with **zxing-cpp WASM**
- 🚀 **Frame processing throughput is 5x faster** than the original library
- ✅ **Recognition speed and success rate improved by 10x**
- 🎯 Solved the low success rate problem of the upstream library. Stable scanning at almost any angle
- Great performance for blurry, skewed, low-light barcodes and QR codes
- WASM-powered, runs natively in browsers, compatible with web frontends
- Retains all core capabilities from the upstream repository
